One-line: the tinted box that says what is about to happen, or what the user must say to the customer right now.

```jsx
<Callout tone="warning">À dire au client maintenant : les plaquettes arrivent lundi, la moto ressort ce soir sans ce travail.</Callout>
<Callout tone="accent" edge icon="ri-lightbulb-line">Vous pouvez déjà prendre des rendez-vous dès que les ponts sont déclarés.</Callout>
```

- Write the consequence, not the category. Never "une erreur est survenue".
- `edge` for advice inside a form; the tinted fill for a condition that blocks or changes the outcome.
